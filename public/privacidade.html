Para que servem

Os dados deste formulário são usados somente para:

  • fazer o registro do associado nos Escoteiros do Brasil, pelo sistema Paxtu;
  • cuidar da segurança do associado durante as atividades do grupo (por isso pedimos a ficha médica).

Não usamos os dados para propaganda nem os vendemos ou repassamos a terceiros.

O que acontece quando você envia

  • As respostas são enviadas por e-mail, como um arquivo anexo, para a conta da secretaria do grupo.
  • Este site não guarda os dados: não há banco de dados nem cópia no servidor.
  • A secretaria lança os dados manualmente no Paxtu, o sistema oficial dos Escoteiros do Brasil, que tem sua própria política de privacidade.

Quem tem acesso

  • A secretaria e a diretoria do grupo, para fazer o registro.
  • Os escotistas responsáveis pelas atividades, apenas no que for necessário para a segurança do associado (por exemplo, alergias e medicamentos).

Serviços usados pelo formulário

Para ajudar no preenchimento, o formulário consulta dois serviços públicos:

  • ViaCEP: recebe apenas o CEP digitado, para preencher o endereço;
  • IBGE: recebe apenas o estado escolhido, para listar as cidades.

Não usamos cookies, ferramentas de estatística nem scripts de terceiros.

Rascunho no seu aparelho

Enquanto você preenche, as respostas ficam salvas apenas no navegador deste aparelho, para não se perderem se a página fechar. O rascunho é apagado automaticamente depois do envio. Se estiver usando um aparelho compartilhado, use o botão “Limpar e recomeçar” ao terminar.

Dados de saúde e de crianças

A ficha médica contém dados sensíveis e, muitas vezes, de crianças e adolescentes. Por isso pedimos a autorização de quem preenche (o próprio associado adulto ou o responsável legal), conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018), e tratamos essas informações com sigilo.

Seus direitos

Você pode pedir, a qualquer momento, para consultar, corrigir ou excluir os dados enviados por este formulário. Para isso, fale com a secretaria do grupo, pessoalmente nas atividades ou pelos canais de contato oficiais do grupo.

Lembramos que os dados já registrados no Paxtu seguem as regras dos Escoteiros do Brasil enquanto o associado estiver registrado.
